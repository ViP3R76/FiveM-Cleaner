# Sicherheit

## Sicherheitsprobleme melden

Bitte melde Sicherheitslücken nicht öffentlich als GitHub Issue.

Für sensible Sicherheitsmeldungen nutze bitte die privaten Kontaktmöglichkeiten des Repository-Besitzers auf GitHub.

## Grundsätzlich

- Lade die ausführbare Datei ausschließlich aus dem offiziellen GitHub-Repository bzw. dessen Releases herunter.
- Prüfe bei Bedarf den veröffentlichten SHA-256-Hash der EXE.
- FiveM CLEANER sollte nur mit einer vertrauenswürdigen Version der Software verwendet werden.

Aktuell unterstützte Version: **v1.0.0**
